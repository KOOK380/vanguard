# Keyword plan

Researched 2026-11-03. Pages follow [strategy.md](strategy.md). Targeting: Abu Dhabi, Dubai and the UAE.

## How to read this plan

**There is no search volume or difficulty data here.** We used web search, not a keyword tool, and results came from a US-based tool rather than a UAE browser. Keywords were chosen from three things: the services we can source, what competitors put in their page titles, and what kind of result each search returned. Check volumes in Google Keyword Planner and Search Console before treating any term as high priority.

**Dubai:** titles may name Dubai as a service area, because About Us says the company operates in the UAE. No page may suggest a Dubai office (decision 82).

## Terms we won't target

Using these would imply something we can't source (decision 83).

| Terms | Why |
|---|---|
| "best", "top", "leading" | Rank claims |
| "certified", "ISO", "approved vendor", "ADNOC approved" | No certification or approval is sourced |
| Siemens, Rockwell, ABB and other platform names | No platform or partnership is sourced |
| "DCS", "RTU", "ESD", "fire and gas", "substation", "pump station", "vibration" | Not named in Vanguard's sourced scope |
| "industrial automation projects", "case studies" | No project is sourced |
