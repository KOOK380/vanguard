# Tone of voice

Written 2026-11-03. Applies to all site copy, including buttons, form messages and alt text.

## The voice

We sound like a capable engineer explaining the work to another professional.

| Trait | What it means | What it doesn't mean |
|---|---|---|
| **Confident** | State what we do, plainly | Claiming to be the best |
| **Technical but clear** | Use correct terms such as SCADA, PLC and instrumentation | Stacking jargon, or explaining basics to engineers |
| **No hype** | Let the scope make the case | Adjectives doing the work of evidence |
| **Short** | One idea per sentence | Choppy fragments that lose the meaning |

## Writing rules

1. **Keep sentences short.** Aim for under 20 words. The limit is 25.
2. **Keep paragraphs short.** Use three sentences at most.
3. **Say "we" and "you".** Use "Vanguard Technology" for first mention on a page, and when the name helps clarity.
4. **Use active verbs.** Write "We install the system", not "The system is installed".
5. **Lead with the useful part.** Scope comes first, and context second.
6. **Avoid contractions and idioms.** Many readers work in English as a second language, so write "we will" and "get in touch" rather than "we'll" and "touch base".
7. **Use sentence case for headings and buttons.** Keep capitals for names and acronyms.
8. **Start buttons with a verb.** Use the labels in [strategy.md](strategy.md).

## Claims

Every fact must have a source in [research.md](research.md), or come from an explicit project instruction logged in [decisions.md](decisions.md).

- **Don't compare or rank.** Avoid "the only", "the best" and "leading".
- **Don't imply projects.** "Our systems control district cooling plants" follows the site's own statement. "We delivered a plant for…" needs a named, sourced project.
- **Don't add detail to a sourced claim.** "24/7 support" stays as it is, with no response times.
- **Don't use numbers without a source.** Use a plain proof point instead, such as "Abu Dhabi based". Open-ended figures like "many years" or "numerous projects" are also out.
- **Don't name standards, certifications or vendors** unless they are sourced. The one exception is the neutral standards list on the About page (decision 184), which claims neither use nor certification.
- **Keep Dubai to service area.** Never suggest an office there.

If a useful fact is missing, write around it and add it to [open-facts.md](open-facts.md).

## Words to avoid

| Avoid | Why | Write instead |
|---|---|---|
| world-class, best-in-class, leading, premier, pioneer | Unsupported rank | Say what we do |
| cutting-edge, state-of-the-art, next-generation | Empty | Name the technology |
| innovative, revolutionary, game-changing | Hype | Describe the benefit |
| seamless, robust, holistic, unparalleled, unrivalled | Vague | State the actual result, if sourced |
| trusted by, proud to, passionate about | About us, not the reader | State the fact or leave it out |
| leverage, utilise, synergy, empower | Inflated | use, work with, help |
| solutions, as a filler | Means nothing on its own | Name the system. "Solutions" is fine as the section name |
| guarantee, ensure, always, never fails | Promises we can't support | Describe what we provide |

## British and UAE English

Use British spelling and UAE conventions.

| Use | Not |
|---|---|
| organisation, optimise, specialise | organization, optimize, specialize |
| colour, centre, metre, fibre | color, center, meter, fiber |
| licence (noun), license (verb) | Mixing these up |
| enquiry | inquiry |
| programme for a schedule of work; program for software, as in "PLC programs" | Mixing these up |
| wastewater, as one word | waste water |
| air conditioning | HVAC, except when naming the system type |
| 3 November 2026 | November 3, 2026 |
| 14:30 or 2.30 pm | 2:30 PM |
| AED 1,500 | $1,500 or Dhs |
| +971 2 626 8001 | +971 26268001 |
| Abu Dhabi, UAE | Abu Dhabi, U.A.E. |

Don't use the serial comma, unless a sentence needs it to be clear.

Use common technical acronyms without expansion on technical pages. Expand a less common one on first use, for example "safety instrumented systems (SIS)".

## Examples

| Current site | Our voice |
|---|---|
| "Vanguard Technology is a pioneer in Industrial Engineering and Applications Development that provides world-class solutions to global clientele" | "Vanguard Technology is an industrial automation company in Abu Dhabi." |
| "We think beyond the machines in order to deliver the true excellence" | "We use proven technologies and a practical approach." |
| "Our maintenance program offers low cost, high value support" | "We offer annual maintenance contracts and field services." |

## Microcopy

| Item | Example |
|---|---|
| **Primary button** | Start a consultation |
| **Form error** | Enter your email address so we can reply. |
| **Form success** | Thank you. We have received your enquiry. |
| **Alt text** | Open control cabinet with wired modules. Describe what is visible, with no claim that it is Vanguard's work. |
| **404** | We can't find that page. This one heading is the agreed exception to the contractions rule, as set in [keyword-plan.md](keyword-plan.md). |

## Checklist

- Every factual claim has a source or logged instruction.
- No words from the avoid list.
- No sentence over 25 words.
- No numbers without a source.
- British spelling throughout.
- It still makes sense to an engineer reading quickly on a phone.
